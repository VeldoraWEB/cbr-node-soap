# SOAP-прокси для ЦБ РФ

## Описание
Учебный проект, реализующий взаимодействия с SOAP-сервисом Центробанка РФ
- `client.js` — SOAP-клиент пользователя
- `proxy.js` — SOAP-сервер, который принимает запросы и транслирует их в ЦБ РФ

## Установка и запуск
1. Установите зависимости:
   ```bash
   npm install
Выберите даты в файле client.js / dateFrom и dateTo
2. Запустите 2 терминала
3. В первом терминале пропишите node proxy.js
4. Во втором node client.js
5. Отобразится результат
