# SOAP-прокси для ЦБ РФ

## Описание
Учебный проект, реализующий взаимодействия с SOAP-сервисом Центробанка РФ
- `client.js` — SOAP-клиент пользователя
- `proxy.js` — SOAP-сервер, который принимает запросы и транслирует их в ЦБ РФ

## Установка и запуск
1. Установите зависимости и выберите даты в файле client.js / dateFrom и dateTo:

   ```bash
   npm install
3. Запустите 2 терминала
4. В первом терминале пропишите node proxy.js
5. Во втором node client.js
6. Отобразится результат
